SI-SISWA Versi 2.0

Aplikasi pengelolaan data peserta didik untuk SD Negeri Kiupunu dengan dashboard yang lebih informatif dan siap dikembangkan menjadi sistem online multi-perangkat.

Dashboard ProfesionalStatistik, distribusi rombel, dan aksi cepat.
Import ExcelMembaca file XLS/XLSX langsung dari browser.
PencarianCari berdasarkan nama, NISN, NIPD, atau NIK.
Filter RombelMenampilkan siswa berdasarkan kelas.
Detail SiswaMelihat seluruh kolom data siswa.
ExportMengunduh kembali data peserta didik sebagai Excel.
Rencana tahap berikutnya: login Admin/Guru dan database online agar data dapat diakses dari beberapa perangkat.
